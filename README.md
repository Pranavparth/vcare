# V Care redesigned website

Six responsive static pages. Open index.html or serve this folder with any static host.

The original Desktop/Vcare files were not modified. The existing chatbot engine and knowledge base are preserved; chatbot styling and keyboard accessibility were updated.

Partner names come from the original website. Edit index.html and products.html to change the two matching partner sets. Motion pauses on hover, has a pause button, and respects reduced-motion preferences.

The contact form prepares a mailto email draft; it does not submit enquiries to a server. To enable direct submission, connect an email/form backend before launch.

Google Fonts are optional external assets; system sans-serif fallbacks work offline. No build tools or dependencies are required.

Validation: JavaScript syntax checks, local file-link checks, desktop visual preview, 390px mobile layout, menu and chatbot interaction. Company claims inside the preserved chatbot come from the supplied original code and should be reviewed before publishing.

Revision: blue and ivory palette; original content restored; wide company logo and eleven original SVG partner graphics reused. Catalogue tabs and category filters work. Founder spotlight on Home and About.

Latest revision: stock content photos removed; product/AMC sections use text-only layouts. Homepage contact is a compact enquiry band linking to a shorter dedicated contact form. Blue theme, founder, chatbot and partner logos retained.
